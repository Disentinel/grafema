## Clarifications (non-binding guidance)

### Always permitted — no license needed
- Using Grafema to analyze your own or your employer's codebase
- Integrating Grafema MCP server into AI coding agents
- Building internal tools and dashboards on top of Grafema
- Using Grafema in CI/CD pipelines (GitHub Actions, etc.)
- Consulting: installing and configuring Grafema for clients
- Security auditing and code review using Grafema
- Academic research and education
- Contributing plugins, analyzers, and language support
- Publishing Enox manifests to the registry
- Mirroring the public registry for internal use

### Commercial embedding
Want to embed Grafema in your product? We offer commercial licenses with revenue share.
Contact: licensing@grafema.dev

### Requires a commercial license
- Offering Grafema's analysis as a hosted/managed service
- Embedding Grafema as the core analysis engine in a competing code intelligence or code context product
- Reselling Grafema or its output under a different brand
- Operating a competing commercial package registry built on Grafema-generated manifests

### Ask us (licensing@grafema.dev)
- Platform integrations where Grafema is one of many features
- OEM/embedded use in non-competing products
- Any use case you're unsure about
