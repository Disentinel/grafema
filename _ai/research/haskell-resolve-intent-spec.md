## Извлечённый ИНТЕНТ (общий для обоих резолверов)

Для вхождения (REFERENCE или CALL) **неквалифицированного** значения-имени `N` в файле
`F`, в позиции с лексическим скоупом `S`:

1. **Ближайшее лексически-объемлющее связывание** `N`, видимое в `S`
   (param / let / where / lambda binder, вверх по скоупам до модуля). [лексический скоуп Haskell]
2. Иначе — **top-level связывание** `N` в том же файле (взаимная рекурсия / forward-refs
   корректны — top-level плоский, позиция не важна).
3. Иначе, если `N` **импортирован** — НЕ резолвить здесь (зона cross-module резолвера).
4. Иначе, если `N` — **Prelude/base** имя в скоупе — резолвить в stdlib/global сущность.
5. Иначе — оставить нерезолвленным (ребро не эмитить).

**ИНВАРИАНТ (из семантики, не из кода): результат — ФУНКЦИЯ. Ровно одна цель или ни одной.**

- Квалифицированные имена (`Mod.f`) — НЕ локальные → не зона этого резолвера.
- Разница refs/calls: только фильтр типа цели (CALLS → вызываемое значение-namespace) и
  тип ребра (READS_FROM / CALLS). Семантика скоупа одна.
- Интент-порядок приоритета: **nearest-local > same-file-top-level > import > prelude**.

## Ground-truth (из семантики Haskell, НЕ из legacy) — фикстуры верификации

1. **Param-shadowing**: `f x = x` и `g x = x` — каждая ссылка `x` → СВОЙ параметр (не чужой). [v2-баг: фанаут в 167]
2. **where-local затеняет top-level**: `n = 1; f y = g where g = n` — `n` внутри `f` → top-level `n` (нет локального `n`); но `f a = a where a = 5; r = a` → `a` → локальный.
3. **Взаимная рекурсия top-level**: `even' 0=True; even' k=odd'(k-1); odd' ...` — `odd'` в теле `even'` → top-level `odd'` (forward-ref, позиция не важна). [фоллбэк обязан резолвить]
4. **Квалиф. вызов не локальный**: есть локальный `lookup`, и вызов `Map.lookup` — `Map.lookup` НЕ должен уйти в локальный `lookup` (Q3).
5. **Prelude**: ссылка `map` без локального `map` → stdlib/global (Q2).
6. **Импорт vs локал**: `import D (cfg)` и локальный `cfg` в функции — ссылка на `cfg` внутри функции → ЛОКАЛ (Q1: локал затеняет импорт).

## Вердикты Вадима (2026-06-14) — интент ратифицирован

- **Q1 → ЛОКАЛ ЗАТЕНЯЕТ ИМПОРТ.** in-scope локальный binder N выигрывает; import-skip применять только когда нет локального связывания N в скоупе. Порядок: nearest-local > same-file-top > import > prelude.
- **Q2 → УНИФИЦИРОВАТЬ PRELUDE с haskell-globals** (effects-db/stdlib), убрать хардкод-список. Пререквизит: проверить, что haskell-globals покрывает value-REFERENCE (не только CALL); если нет — расширить его, не плодить хардкод.
- **Q3 → КВАЛИФ. = НЕ ЛОКАЛЬНЫЙ.** Убрать strip+local-resolve для `Mod.f`; квалиф. вызовы отдаём cross-module резолверу.

## Крюк реализации single-target (живой код движка)

- `parser_ext.rs:886` → `E-AGG-001`: **агрегаты (`Var = agg {...}`) ЗАПРЕЩЕНЫ в Gate A**. Нет builtin сравнения id/строк.
- ⇒ single-target по **namespace-приоритету** (FUNCTION>VARIABLE>…, без TYPE_SIGNATURE) — выразим через `\+ exists_better` (без нового примитива).
- ⇒ single-target **тай-брейк среди одинаковых** (N одноимённых PARAMETER в одном FUNCTION-scope) — **НЕВЫРАЗИМ** паком.
- v2-фанаут: 64 074/64 102 рёбер = PARAMETER (334 источника × 167). Доминирующий класс **паком в одиночку не чинится**.

## Вывод по реализации (sequencing)

- **REFS-пак ЗАБЛОКИРОВАН на finer-scope анализатора**: haskell-analyzer должен эмитить лексические SCOPE-ноды per clause/lambda/where и CONTAINS'ить локалы от них (сейчас всё уплощено в FUNCTION-scope). Тогда в каждом scope ≤1 одноимённый binder → пак естественно single-target и отвечает интенту (nearest lexical binder). Это же закрывает residual локальных FUNCTION'ов. Корневой энаблер; согласуется с тезисом Grafema (граф должен честно представлять лексический скоуп).
- **CALLS-пак можно отгрузить СЕЙЧАС** независимо: namespace-приоритет + выкинуть TYPE_SIGNATURE (Q-фикс) + Q3 (квалиф skip) + Q1 (локал затеняет импорт). Вызовы редко попадают в same-name-param фанаут → чисто.
- **Альтернатива finer-scope** — снять запрет агрегатов в движке (E-AGG-001). Больше/политика Gate A; finer-scope корректнее структурно → предпочтительнее.
- **Guarantee на функциональность резолва** (≤1 цель/источник/resolvedVia) — гейтит регрессии механически, независимо от пути.
